# Banking Network Infrastructure – Cisco Packet Tracer

## Overview

A simulated banking network infrastructure designed and implemented using Cisco Packet Tracer.

The project demonstrates fundamental networking concepts including network segmentation, VLANs, IP addressing, routing, DHCP, and basic network security.

## Project Objectives

* Design a secure banking network topology
* Separate departments using VLANs
* Configure IP addressing and subnetting
* Implement inter-VLAN communication
* Configure routing between network segments
* Configure DHCP for end devices
* Test connectivity between departments and branches
* Apply basic network security configurations
